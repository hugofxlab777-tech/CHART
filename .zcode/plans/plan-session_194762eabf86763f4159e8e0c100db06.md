# Durak — UI/UX tvarkymo planas

Tikslas: pilnas UI/UX sutvarkymas pagal vartotojo pasirinkimą — paslėpti Online Multiplayer, pilnas tvarkymas (pranešimai, fokuso valdymas, konsistencija), debug mygtukas tik dev režimu, netikri leaderboard įrašai pažymimi/šalinami. Viskas lietuviškai.

## 1. Pranešimų sistema (pakeičia alert/confirm)
- `src/systems/Toast.ts` (naujas): nedragantis toast/pranešimų komponentas (sėkmė, klaida, info) + paprastas patvirtinimo dialogas (confirm modal).
- Pakeisti: JSON kopijavimas (`Hud.ts:253`), kambario sukūrimas (`Game.ts:167-170`), restarto patvirtinimas (`Game.ts:187`).

## 2. Online Multiplayer paslėpimas
- Pašalinti/išjungti mygtukus header ir mobile drawer bei modalą `index.html:193-208`; `OnlineMultiplayer.ts` kodas paliekamas (nenaudojamas).

## 3. Modalų pataisymai
- ESC uždaro visus modals (Setup, Leaderboard, GameOver, Rules, JSON) — dabar `Hud.ts:258-265` jų neuždaro.
- Fokuso valdymas: atidarius modalą — fokosas į jį, uždarius — grąžinamas į paskutinį elementą; paprastas focus-trap.
- Rules modalas: pašalinti „Kraunama informacija..." placeholder (`index.html:165`) — turinys sinchroninis, įdedamas iškart.

## 4. Rodymo/slėpimo konsistencija
- Vienas mechanizmas: `.hidden` klasė visur; pašalinti `style.display` perjungimus (`Hud.ts:268-282, 327, 341, 445-447`) ir dvigubą `class="hidden" style="display:none"` (`index.html:86`).
- Sumažinti `!important` naudojimą (`styles.css:688-697`).

## 5. Tekstai ir kalba
- Suvienodinti lietuvišką tekstą („Online Multiplayer", „Host", „Custom", kabutės `Hud.ts:483`), peržiūrėti pavadinimo „HUGOLAB Royal Edition" formulavimą.

## 6. Šiukšlės
- Debug JSON mygtukas: rodomas tik `import.meta.env.DEV` (header + drawer).
- Leaderboard: demo įrašus pažymėti „Demo" žyme arba pašalinti (`src/engine/Leaderboard.ts:30-36`).

## 7. Vizualinis poliravimas (ribotas, be pertvarkymo)
- Piktogramos: palaipsniui keisti emoji piktogramas į vientistą stilių (inline SVG arba vienodas emoji rinkinys), priklausomai nuo esamos būsenos.
- Tipografikos/hover būsenų peržiūra pagal threejs-game-ui-designer gaires; išlaikyti esamą tamsiai žalią/auksinę temą.

## 8. Performance smulkmenos
- Opponent strip (`Hud.ts:424-435`) neperrenderinamas kiekvienam `update()` — tik kai pasikeičia duomenys (paprastas dirty-check).

## Tikrinimas
- `npm run dev` + naršyklės patikra desktop (~1280×800) ir mobile (~390×844) viewport'uose: visi modals atsidaro/užsidaro (ESC + mygtukas + backdrop), toast pranešimai veikia, online mygtukų nėra, debug mygtukas nematomas production build'e.
- `npm run build` — production build be klaidų.
- Playwright UI testai (jei veikia) arba rankinė peržiūra su screenshots `artifacts/` kataloge lyginimui.
